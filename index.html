Projects

2026CV + embedded

Vision-Based Driver Drowsiness Detection & Smart Vehicle Control

A webcam watches the driver's eyes in real time using OpenCV. If the eyes disappear (closed or looking away), the Python script tells an Arduino over serial to stop the vehicle's motor. When the eyes are detected again, the motor starts back up.

  • Eye detection with OpenCV's Haar cascade classifier, drawn live on the video feed
  • Python sends 1 or 0 over USB serial; the Arduino drives the motor through an L298N driver with PWM speed control
  • Python
  • OpenCV
  • PySerial
  • Arduino (C++)

2026GenAI pipeline

VisionTale: Cinematic Stories from Text

Write a short scene and it becomes a narrated mini film. The text is split into story beats, an AI image is generated for each, and the browser reads it aloud while highlighting every spoken word. Factual text is detected first and skips image generation, and scenes are generated in parallel, cutting the wait from about 20s to 4s.
